# Modification notice

This project is derived from the Drupal 7 **Responsive Menu** module, release 7.x-3.7:

https://www.drupal.org/project/responsive_menu

The following files were modified in October 2026 to add and support the bottom-dropdown menu mode:

- `responsive_menu.module`
- `responsive_menu.info`
- `includes/responsive_menu.admin.inc`
- `js/responsive_menu.config.js`
- `css/responsive_menu.css`
- `theme/responsive-menu-block-toggle.tpl.php`

The following compatibility stylesheet was added:

- `css/responsive_menu.admin.css`

The modifications add responsive multi-column layout, hierarchical submenu panels, active-trail initialization, split parent-link/submenu controls, separator controls, accessibility attributes, header-relative positioning, administration-route isolation, and toolbar compatibility.
